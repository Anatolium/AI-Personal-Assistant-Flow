# AI-Personal-Assistant-Flow
A multimodal Telegram assistant with a RAG system, image analysis, and voice interface
Personal Assistant Flow — интеллектуальный помощник, объединяющий работу с данными и мультимодальность:

🧠 RAG (Knowledge Base): Точные ответы на основе ваших документов (контакты, FAQ, правила).

🎙️ Voice First: Распознавание входящего аудио и синтез голосовых ответов.

👁️ Vision: Анализ и описание содержимого изображений.

💬 Smart Context: Сохранение истории переписки для полноценного диалога.

📱 Platform: Удобный интерфейс на базе Telegram.
